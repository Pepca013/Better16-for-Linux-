# Unofficial Better 16 Client for Linux

you can now play better 16 roblox revival on linux using proton and some magic terminal stuff

## How  it works?
the program uses Valves software called Proton and that program makes windows apps run on linux so we can use better16 windows client to run RobloxPlayerLauncher.exe file and tweaking browser things and done
